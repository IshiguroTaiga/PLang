## Quick Clone & Run Commands

```bash
# 1. Clone the repository
git clone https://github.com/IshiguroTaiga/PLang.git
cd PLang

# 2. Launch the Interactive CLI REPL
python main.py

# 3. Run Sample .plang Scripts
python main.py examples/integer_arithmetic.plang
python main.py examples/hybrid_syntax.plang
python main.py examples/advanced_features.plang
python main.py examples/real_world_formulas.plang
python main.py examples/error_handling_demo.plang

# 4. Run Automated Pytest Verification Suite
python -m pytest test_lang.py -v

# 5. Launch Interactive React Web Studio IDE (Optional)
- **Website link**: [https://p-lang-eight.vercel.app/](https://p-lang-eight.vercel.app/)
```
